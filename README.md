# Smart Building Monitoring

Application de monitoring et d'analyse de logs
pour un environnement IoT / Smart Building.

## Objectif

Centraliser, traiter, rechercher et analyser les logs
provenant des capteurs d'un bâtiment intelligent.

## Technologies

- Docker et Docker Compose
- Elasticsearch
- Logstash
- Kibana
- MongoDB
- Redis
- Python / Flask (backend prévu)

## Organisation

- logstash/ : configuration des pipelines Logstash
- data/ : données de test locales
- docs/ : documentation et diagrammes
